# DevShell v26.11.3-rc.2 · 构建 2026111002

v26.11.3 线第二个候选构建：内置更新 rc 通道的候选版本发现改用 github.com 的 releases.atom 订阅源，不再消耗匿名 GitHub API 配额；更新加速域名新增自动连通性检测。rc 之间可内置更新升级。

调整：内置更新 rc 通道的版本发现改用公开 releases.atom 订阅源（github.com 域，无 API 限流）：此前匿名 API 配额耗尽（60 次/小时，403）会让 rc 检查更新一直报「网络不可用或无法访问更新源」；订阅源只列已发布的版本，候选仍按版本逐个读取清单并完整校验产品、平台、构建号与 SHA-256，信任链不变。release 通道沿用原有 /releases/latest 下载地址，不受影响；加速域对 rc 通道的发现与下载同样生效。

新增：GitHub 更新加速域名对话框自动连通性检测：打开、切换预设与保存后自动探测，按更新列表源、更新下载源两类分别显示该加速域是否可用及耗时（无法连接 / HTTP 状态 / 返回内容异常）；加速域不能代理某类地址时选中即刻可见，检测失败仍自动回落直连的行为不变。
