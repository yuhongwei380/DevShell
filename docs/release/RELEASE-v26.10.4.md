# DevShell v26.10.4 · 构建 2026103102

本正式版汇总 v26.10.4-rc.1 至 rc.5 的全部改动；rc 用户可通过内置更新直接升级到本版本。

新增：快速连接支持 `ssh -L` 本机端口转发：粘贴含 `-L` 的命令行即可，
      连接成功后自动监听 127.0.0.1 并经会话通道转发，会话关闭自动收回。
      转发规则随保存的连接持久化，下次连接自动生效；支持多条 `-L` 与 `127.0.0.1` 绑定写法；
      本机端口被占用时仅在终端告警，不中断连接。
新增：快速连接支持 `ssh -vvv` 连接诊断：-v 握手摘要与连接样本直写诊断日志，
      -vv 追加保活守卫计数，-vvv 追加传输层数据包活动时间线；
      握手、后台通道与断开诊断同时在终端显示，并记录协商算法和协议错误类别。
调整：Dropbear 连接默认关闭 SFTP 文件功能，并显示关闭状态。
修复：内置更新被旧格式（11 位）构建号收据的高水位压制，再也发现不了新版本；收据自动抬升至当前构建后恢复正常。
修复：SSH 终端连接 Dropbear 服务器空闲约 5 秒即被断开；通道保活守卫每 5 秒发送保活询问直至连接关闭。
修复：Dropbear 并发后台通道可能导致 SSH 终端断联。
修复：传输诊断的收包等待时间统计不准确。
