# DevShell v26.10.2-rc.1 · 构建 2026102501

本版为 v26.10.2 的第一个测试版（rc.1）。已安装 v26.10.1 正式版的用户可直接通过内置更新升级；测试版之间、测试版转正式版均可内置更新，正式版装回测试版需手动安装。

## 本次变化

- 新增：命令输入条在本机提示符（欢迎页，或远端 Shell 已退出的标签）支持 `Tab` / `Shift + Tab` 补全功能命令：`ssh`、`reconnect`、`ping`、`traceroute`、`nslookup`、`dig`、`curl`、`help`、`exit`。
- 新增：补全时输入条上方弹出候选框，显示参数格式与用途说明；多候选先补公共前缀，连续 `Tab` 循环切换候选，输入、回车或 `Esc` 收起。已连接会话不拦截 `Tab`，补全仍由远程 Shell 负责。
