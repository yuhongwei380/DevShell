# DevShell v26.10.3 · 构建 2026102703

本正式版汇总 v26.10.3-rc.1 至 rc.7 的全部改动；rc 用户可通过内置更新直接升级到本版本。

新增：`rz` 与 SFTP 上传在终端内显示小型浮动进度条，按当前 SSH 会话汇总服务器已确认的进度。
新增：SFTP 收起时仍显示 rz 等上传任务的进度，完成后提示“上传已完成”，可点击查看任务。
调整：默认最小窗口宽度为 1100px，小屏幕以可用工作区为限，确保 Shell 功能按钮可见。
调整：右侧 SFTP 打开时扩展窗口、关闭时收回，支持切换布局与快速开关。
调整：项目元数据、源码模块、原生窗口标识、图标资源、诊断工具和当前文档统一使用 DevShell；保留开源许可、上游来源及旧配置兼容标识。
修复：暗色主题下上传进度环出现深色方块，上传状态徽章配色与面板保持一致。
修复：Dropbear 服务器跳过可选 exec 启动脚本，直接请求 SSH shell，兼容 OpenWrt ash 终端启动。
修复：RC 版改为从 GitHub Releases 中选择更新，支持 RC→RC 和 RC→正式版内置升级。
修复：终端滚动条隐藏原生箭头并固定 xterm 滑块宽度，避免滑到两端时覆盖箭头或偏心。
修复：手动检查更新显示完整 RC 版本，并读取当前 RC tag 对应的发版说明。
