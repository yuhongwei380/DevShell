# DevShell v26.11.0-rc.9

构建 2026110108 · 2026-11-01

新增：
- 服务器管理底部「备份/恢复」：连接、分组、托管密钥、代理与受信主机指纹导出为单个 JSON 备份文件，另一台机器导入即恢复。
  - 默认包含已保存的密码、私钥与口令（弹窗明示备份文件为明文 JSON，请妥善保管）；取消勾选只导出结构。
  - 导入按 ID/密钥指纹/同名同地址去重合并，重复导入幂等；悬空密钥与代理引用自动降级；主机指纹只补不覆盖。

修复：
- 更新公告两端显示旧版本标签：发版需同步递增显示版本常量（rc.7/rc.8 曾遗漏），本版本起公告与对话框均显示 v26.11.0-rc.9。
- 「更新日志」对话框查找当前 rc 对应的发版说明，不再回落显示过期基线内容。
- 终端表头状态灯常亮不反映连接状态：现与标签页同规则（已连接绿 / 正在连接蓝 / 待连接·已断开红）。

安全：
- 卸载保留连接凭据的打包硬卫：卸载清单只允许程序文件与捆绑 docs/licenses，stage 出现白名单外文件或递归删除直接拒绝打包；卸载确认页明确「保留连接凭据、个人配置、密钥」。
