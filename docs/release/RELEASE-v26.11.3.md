# DevShell v26.11.3（开发线，当前 rc.1）· 构建 2026111001

本文件为 v26.11.3 版本线的基线发版说明；正式版发布时将汇总全部 rc 改动重写。
当前内容对应 v26.11.3-rc.1：

新增：应用 iTerm 配色方案时除 16 色 ANSI 外，一并读取该方案的前景、光标与选区背景色，终端文字、光标与选区外观随方案生效；终端背景仍不取配色文件的背景色，保持完全透明。

调整：会话标签右键「重命名连接」改为「重命名会话」：只改这个标签自己的显示名，不修改服务器管理、收藏夹里这份连接的名称；提交留空恢复默认；会话未重命名时，标签、终端顶部与命令发送目标默认读取收藏夹、服务器管理里的连接名称；快速连接临时会话同样提供该项。

调整：同服务器会话命名按打开方式区分——双击已连接标签打开的是共用同一条 SSH 连接的渠道会话，标签按「名称 SSH[0]、SSH[1]…」编号；从收藏夹、服务器列表点开的是各自重新拨号的独立连接，同一连接开多个按「名称 · 会话 N」区分，收藏夹点击始终打开独立会话。
