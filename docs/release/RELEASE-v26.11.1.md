# DevShell v26.11.1 · 构建 2026110401

v26.11.1 正式版，以 v26.11.1-rc.8 功能为基线，汇总 rc.1–rc.8 全部改动。构建号高于该版本线全部 rc，rc.1–rc.8 用户可直接内置更新升级到本版本。

修复：背景管理器内置图片背景全部不生效（新增「纯色 · 全黑」时把无图判断误写成 builtin: 前缀匹配，14 个内置图片背景被置空）；现仅两个纯色内置视为无图，内置图片与导入背景一律按强度 0–100% 生效。
新增：SSH 连接支持成功后自动执行预设命令（issue #5）：连接编辑器「连接后自动执行」填写命令（每行一条、最多 50 行），远端 Shell 就绪后按序注入，程序运行或进入 TUI 期间暂停，断开重连后重新执行；串口/RDP 不受影响。总开关位于设置 → 其他功能，默认开启。
新增：本地终端会话（仅限 macOS）：设置 → 其他功能「本地终端」开关（默认关闭）；开启后点会话标签「+」直接新开本机终端（登录 shell、家目录、真实 PTY），断开/重连语义与 SSH 会话一致，标签标注「· 本机」；Windows 不提供。
新增：链接栏连接右键菜单「重命名连接」「保存到服务器管理」（可选既有分组或新建分组，凭据保留）。
新增：服务器管理连接右键「复制到同名连接」：全部配置照抄，已保存的登录密码、私钥口令与代理口令随副本在存储内完整保留；点击后询问「直接生成 / 生成后修改」。
新增：服务器管理连接右键「固定到链接栏 / 从链接栏取消固定」，与链接栏、会话标签菜单状态互通；会话行「固定」按钮移除，固定入口移入会话标签右键菜单。
新增：连接可直接拖到左侧目录行移动（任意层级、折叠状态亦可，多选整组移动），拖到「未分组」行即移出分组。
新增：分组「⋯」菜单「删除分组（保留连接）」：只删分组本身，组内连接（含回收站）与子分组移交给选定接管分组或未分组，配置、凭据与历史不动。
新增：服务器目录「未分组」筛选行：连接可不属于任何分组，新建/编辑分组下拉可选，点击行即筛选，「移动到…」同步支持。
调整：服务器管理去掉「历史连接」标签，仅保留「服务器 / 已删除」；连接历史仍在后台记录，永久删除连接时一并清除。
调整：服务器目录去掉「全部连接」聚合行与面包屑根节点，顶部固定为「未分组」筛选行；默认视图记住上次选择，失效时落到首个顶层分组或「未分组」。
调整：设置抽屉内下拉行不再绘制分隔线，菜单行距整体收紧；会话标签「+」按钮提示改为「新会话」。
