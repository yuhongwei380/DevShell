# DevShell v26.11.1（开发线，当前 rc.2）· 构建 2026110207

本文件为 v26.11.1 版本线的基线发版说明；正式版发布时将汇总全部 rc 改动重写。
当前内容对应 v26.11.1-rc.2：

新增：SSH 连接支持连接成功后自动执行预设命令（issue #5）：连接编辑器「连接后自动执行」勾选并填写命令（每行一条、最多 50 行）；远端 Shell 就绪后按顺序敲进该会话终端，程序运行或进入 TUI 期间不注入下一条；断开重连后重新执行，串口/RDP 不受影响。
新增：设置新增「其他功能」子页，「连接后自动执行命令」总开关（默认开启）；关闭后所有连接均不再自动执行，已保存的命令保留。

v26.11.1-rc.1（构建 2026110206）：

修复：背景管理器内置图片背景全部不生效（新增「纯色 · 全黑」时把无图判断误写成 builtin: 前缀匹配，14 个内置图片背景被置空，仅导入背景正常）；现仅两个纯色内置视为无图，内置图片与导入背景一律按强度 0–100% 生效。
