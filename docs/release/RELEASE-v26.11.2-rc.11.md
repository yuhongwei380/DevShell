# DevShell v26.11.2-rc.11 · 构建 2026110901

v26.11.2 线第十一个候选构建：终端 ANSI 颜色支持多套 iTerm 配色方案导入管理；主题管理整体下线。rc 之间可内置更新升级。

新增：设置 → 外观配置 →「配色方案」管理页：可一次或分批导入多套 iTerm Color Scheme（.itermcolors）文件，方案名称沿用导入文件名，同名导入即覆盖，最多 64 套，每套可应用、重命名或两步确认删除；ANSI 颜色下拉以分组列出已导入方案。

新增：应用方案后终端只采用其 16 色 ANSI，配色文件的背景、前景、光标等其他键会被忽略，终端仍保持透明背景、文字颜色仍随字体；切换即时生效，真彩色与 256 色语义不受影响。

调整：移除「主题管理」整个功能：整套外观存为独立主题的入口与应用、重命名、复制、删除全部下线，相关界面与设置字段一并删除；旧配置中 themes、appearanceTheme 等残留键加载时自动忽略，字体与其余外观设置不受影响。帮助手册外观章节同步更新。
