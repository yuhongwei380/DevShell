# DevShell v26.11.2-rc.3 · 构建 2026110701

v26.11.2 线第三个候选构建：同服务器 SSH 渠道复制、更新通道选择、连接取消与液态玻璃材质。rc 之间可内置更新升级；v26.11.1 正式版按规则不能内置升级到 rc，需手动安装本 rc 一次。

新增：同服务器会话改为 Xshell 语义——双击已连接标签（或右键「复制同服务器SSH会话」）复用同一条 SSH 连接再开一条独立终端渠道：不再拨号、不认证、不再核指纹；关闭任一标签不影响其余渠道，最后一个标签关闭时连接才断开，传输死亡则全部渠道随之断开。
  会话（标签）菜单取消「新建同服务器会话」；双击已断开标签仍为原地址本标签重连，双击服务器列表或链接栏仍是独立新拨号。
新增：右键「复制链接」（会话标签与链接栏 chip）：按连接配置生成「原会话名-clone」新链接，重名自动避让（-clone 2…），出现在服务器管理；从链接栏进入时自动固定到源链接右侧。同服务器会话需要各自的名字或链接就用它。
新增：手动「检查更新」先选版本通道：release 只查正式版资产，rc 通道读取完整 Releases 列表（含 prerelease），正式版也可直接升级到构建号更新的 rc；启动自动检查仍按当前构建类型自动选择。
新增：正在连接时按 Ctrl+C 可取消连接尝试：中止在途请求、标签立即回到本机提示符，迟到的成功会话一律销毁；凭据与指纹核实对话框同样支持 Ctrl+C 取消。
调整：毛玻璃全局主题升级为液态玻璃折射材质：在经典配色之上叠加玻璃，顶栏与监控区融入画布、仅 Shell 与 SFTP 两面板轻微分隔，悬浮圆角玻璃卡配双层流动光场与棱镜边缘。
移除：全局主题「极地」「夜幕」（保留经典与毛玻璃）；旧配置与主题快照中的所选自动迁回经典。
修复：telnet 拨号成功后连接挂起、无法关闭。
