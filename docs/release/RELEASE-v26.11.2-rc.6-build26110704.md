# DevShell v26.11.2-rc.6 · 构建 2026110704

v26.11.2 线第六个候选构建：液态玻璃 Shell 区毛玻璃化，浅色主题暂停玻璃。rc 之间可内置更新升级；v26.11.1 正式版按规则不能内置升级到 rc，需手动安装本 rc 一次。

调整：液态玻璃下终端面板（Shell 区）半透明毛玻璃化：深色主题透出底层流动光色；修复玻璃面一直被主题层实底覆盖、从未真正生效的样式冲突；会话标签右键菜单与其余弹窗同档玻璃化。
调整：液态玻璃暂不支持浅色主题——浅色画布过亮，半透明面板合成后对比度不足，解析为浅色时自动按经典渲染；偏好保留，切回深色自动恢复玻璃，主题对话框状态文案同步说明。
