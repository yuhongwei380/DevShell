# DevShell v26.11.2-rc.2 · 构建 2026110501

v26.11.2 线第二个候选构建：全局主题（毛玻璃、极地、夜幕）与窗口拖拽修复。rc 之间可内置更新升级；v26.11.1 正式版按规则不能内置升级到 rc，需手动安装本 rc 一次。

新增：设置 → 外观配置 → 全局主题：经典、毛玻璃、极地、夜幕四套整套界面材质，重绘面板、菜单、对话框与强调色，而非仅更换背景；与明暗模式、字体、ANSI、背景、布局彼此正交，切换不重建终端、不中断连接。
  毛玻璃浅色为雾白、深色为烟灰，不使用背景图（原有背景选择保留，切回经典即恢复）；极地取 Nord 北极冷调，夜幕取 Tokyo Night 深夜蓝紫；三套新主题两种明暗下终端均用深色阅读底，保证 ANSI 语义色可读。
  系统不支持透明模糊、开启「减少透明度」或高对比模式时自动回退同色实底；参考微软 Mica 回退与 MDN backdrop-filter 规则。预览工具 `npm run preview:themes` 与截图见仓库 docs/design/。
新增：主题管理保存的整套外观现包含全局主题，快照整套应用时一并切换。
修复：监控栏顶部（品牌区）的空白处此前整块禁用窗口拖拽，按住无法移动窗口；现空白处可拖动窗口，logo、设置、GitHub、主题、锁定图标仍正常点击，双击空白切换最大化。
