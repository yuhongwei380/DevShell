# DevShell v26.11.1-rc.2 · 构建 2026110207

本构建实现 issue #5：SSH 连接成功后自动执行预设命令；rc 用户可直接内置更新升级（rc.1 → rc.2）。

新增：SSH 连接支持连接成功后自动执行预设命令：连接编辑器「连接后自动执行」勾选并填写命令（每行一条、最多 50 行）；远端 Shell 就绪后按顺序敲进该会话终端，程序运行或进入 TUI 期间不注入下一条，回到提示符再继续；断开重连后重新执行，多会话互不干扰；串口/RDP 连接不受影响。
新增：设置新增「其他功能」子页，「连接后自动执行命令」总开关与界面缩放同款下拉，默认开启；关闭后所有连接均不再自动执行，已保存的命令保留。
测试：新增浏览器回归 TestAutoCommandsBrowser（开关默认值与持久化、编辑器空行过滤、省略字段编辑保留命令、提示符门控队列与断开清队、会话隔离）。
