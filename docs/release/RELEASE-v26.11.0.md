# DevShell v26.11.0 · 构建 2026110205

本正式版汇总 v26.11.0-rc.1 至 rc.12 的全部改动与发版后修复；rc 用户可通过内置更新直接升级到本版本。

新增：设置「简洁模式」：一键隐藏监控侧栏、SFTP 面板与终端标题栏，命令输入条自动收起为左侧按钮；默认开启，关闭后 SFTP 面板不自动展开。
新增：设置「更新加速域名」：内置预设或自定义 https 加速下载更新，失败自动回落直连；下载仍强制构建号与 SHA-256 校验。
新增：服务器管理「备份/恢复」：连接、分组、密钥、代理与受信主机指纹导出单个 JSON，跨机导入合并去重、幂等。
新增：链接栏改为书签按钮下方竖向下拉列表：左键连接、右键重命名、拖拽排序、× 取消固定；书签按钮始终显示。
新增：会话标签右键「保存连接」（支持选择/新建分组）与「重命名连接」（与服务器管理同步）；双击已断开标签原地重连。
新增：终端 ANSI 颜色三套 16 色预设；「跟随终端目录」默认开启；上传状态灰底绿色进度环；内置全黑背景。
调整：标题栏整行移除，窗口按钮并入会话栏，logo/设置/主题等移至侧栏列顶部；监控卡片与 shell 区顶对齐。
调整：数据文件名去品牌化（dengshell.* → devshell.*），升级后自动改名迁移、成对回滚；「文件面板」统一更名「SFTP面板」。
调整：SFTP 面板位置、曲线样式、明暗跟随系统等设置归入设置/外观配置，统一为开启/关闭下拉框。
修复：多卡服务器掉卡后 GPU 监控编号错位；终端表头与会话标签状态灯光晕被裁切、状态灯不随连接状态变化。
修复：底部命令输入条右端按钮被面板边缘裁切；更新公告两端显示旧版本标签；应用图标白色外框与留白。
修复：检查更新后若发版被重新发布，下载按旧清单校验必然提示 SHA-256 校验失败；现自动刷新更新清单并重试一次。
安全：卸载不删连接凭据的打包强校验：卸载清单只允许程序与捆绑文件，一旦混入用户数据或递归删除立即中止打包。
