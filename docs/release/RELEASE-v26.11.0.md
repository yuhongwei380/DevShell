本文件为 v26.11.0 版本线的基线发版说明；正式版发布时将汇总全部 rc 改动重写。
当前内容对应 v26.11.0-rc.1：

新增：终端上传状态改为灰底绿色圆环进度，进度数字居中于圆环内。

新增：双击已断开的会话标签即用原地址在该标签重新连接。
调整：取消终端工具栏重新连接按钮；本机提示符 reconnect 命令仍可用。
