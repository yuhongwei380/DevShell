# DevShell v26.11.2-rc.8 · 构建 2026110802

v26.11.2 线第八个候选构建：SSH 握手失败诊断修复。rc 之间可内置更新升级；v26.11.1 正式版按规则不能内置升级到 rc，需手动安装本 rc 一次。

修复：握手失败时 -vvv 诊断不再一片空白——失败事件的记录 key 曾截断连接 ID，前端始终取不到；现按完整 ID 记录，握手耗时、认证方法轨迹与错误类型即时可见并落盘。
修复：Windows 上连接被复位/中断曾被误分为 transport-or-channel-error——socket 错误携带的是 WSA 原始码（10054/10053），现在 errno 与 WSA 两种拼写都能正确识别。
新增：握手阶段被服务器关闭连接时给出明确提示：说明尚未进入身份验证、与密码或密钥无关，并列出端口填错、sshd 并发限制（MaxStartups）、hosts.deny/fail2ban、代理链路中断等常见原因。
