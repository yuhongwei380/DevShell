# DevShell v26.11.2-rc.9 · 构建 2026110803

v26.11.2 线第九个候选构建：SSH 握手失败提示写明拨出地址。rc 之间可内置更新升级。

修复：握手失败的弹窗与 -vvv 诊断事件现在写明拨出的「主机:端口」——服务器换过端口后，旧连接仍保存旧端口、拨到非 SSH 服务时，一眼可见拨到了哪里，并附「请核对该连接的端口与代理配置」指引；不再只有干巴巴的 ssh: handshake failed: EOF。
修复：-vvv 事件补齐 target= 与 stage=dial/handshake 标记；此前 TCP 拨号本身失败不记录任何事件，现在补记 stage=dial 事件，耗时与错误类型可在诊断日志中回放。
修复：连接被拒新增 connection-refused 错误分类（含 Windows WSA 原始码 10061），与握手阶段断连区分开。
