# DevShell v26.11.1-rc.3（构建 2026110208）

新增：本地终端会话（仅 macOS）：设置 → 其他功能新增「本地终端」开关（默认关闭）。开启后点会话标签「+」直接新开本机终端：登录 bash/zsh、起始目录为家目录、真实 PTY；断开提示与重新连接语义与 SSH 会话一致（退出后内容保留，可在原标签重新打开），标签标注「· 本机」，不会产生已保存连接。Windows 本版不提供该功能。
调整：会话标签「+」按钮提示由「新选项卡」改为「新会话」。
说明：新增浏览器回归 test-local-shell-browser（Windows 断言功能隐藏、开关与创建接口被拒；支持平台断言真实会话打开、输入回传、退出断连与开关持久化）；本地终端 HTTP/WebSocket 协议与 SSH 中继一致。
