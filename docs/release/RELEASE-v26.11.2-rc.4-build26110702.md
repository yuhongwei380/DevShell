# DevShell v26.11.2-rc.4 · 构建 2026110702

v26.11.2 线第四个候选构建：复制渠道断开修复、链接栏更名收藏夹、复制独立会话。rc 之间可内置更新升级；v26.11.1 正式版按规则不能内置升级到 rc，需手动安装本 rc 一次。

修复：复制同服务器SSH会话后新标签立即断开变红——渠道复制标签的终端被接入两次、遭后端 409 拒绝，现仅由终端创建自动接入一次；复制渠道会话同时补上初始工作目录，预置启动命令不再因此失败。
调整：「链接栏」整体更名为「收藏夹」：入口文案改为「加入收藏夹 / 从收藏夹取消收藏 / 取消收藏」，空态提示、tooltip、aria 与使用手册同步；收藏夹 chip 菜单的「复制链接」等入口保持不变。
调整：会话标签右键菜单取消「复制同服务器SSH会话」，复制渠道仅保留双击已连接标签（行为不变）。
调整：会话标签菜单「复制链接」更名「复制独立会话」：生成「原会话名-clone」后立即重新拨号打开一条独立会话；新会话是单独的已保存连接，可单独保存到收藏夹或服务器管理并各自改名。
