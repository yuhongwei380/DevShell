# DevShell v26.11.1-rc.7（构建 2026110304）

新增：分组「⋯」菜单新增「删除分组（保留连接）」：只删分组本身，组内连接（含回收站中的）与子分组整体移交给选定的接管分组（默认上级分组），连接配置、已保存凭据与连接历史不受影响。
新增：服务器目录新增「未分组」筛选行：连接允许不属于任何分组；新建/编辑连接的分组下拉可选「未分组」，点击筛选行列出全部无分组连接，把连接拖到该行即移出分组；「移动到…」同步提供该目标。
调整：「删除分组（保留连接）」支持把连接与子分组移交为未分组（子分组回到顶层），取消原先「必须先创建其他接管分组」的限制。
调整：设置抽屉内的下拉行不再绘制分隔线，与按钮行统一为一个列表，菜单整体行距略收紧。
