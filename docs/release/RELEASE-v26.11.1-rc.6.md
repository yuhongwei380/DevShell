# DevShell v26.11.1-rc.6（构建 2026110303）

调整：「复制到同名连接」点击后先询问「直接生成」或「生成后修改」：后者随即打开该副本预填好的连接编辑页（凭据提示「已保存，留空保留」），关掉编辑页也保留已生成的副本；取消则不生成。
新增：服务器管理的连接可直接拖到左侧目录行移动（任意层级、折叠状态亦可），拖动经过时整行高亮、列表边缘自动滚动；拖起多选中的卡片时整个选中组一起移动。历史/已删除视图不提供拖拽，与分组同级拖拽排序互不干扰。
说明：test-server-move 扩展复制三分支与拖拽（单选/多选）断言；修复 test-groups-editors 因缩放钳制公式而必然失败的过时断言。
