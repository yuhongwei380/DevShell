# DevShell v26.11.0-rc.5 · 构建 2026110104

新增：设置菜单「更新加速域名」——直连 GitHub 失败或受限时，可选内置加速域名（gh-proxy.org / gh-proxy.com / ghfast.top / mirror.mikus.ink）或填写自定义 https 地址。
  更新清单与安装包下载优先走加速域名（ghproxy 前缀方式），失败自动回落直连 GitHub；留空即保持直连。
  下载仍强制校验产品、平台、构建号、大小与 SHA-256，加速域名只改变下载通道、不改变信任链。
新增：检查更新失败时提示可配置加速域名后重试；更新弹窗显示实际来源（加速域名或直连）。
