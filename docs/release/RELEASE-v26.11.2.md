# DevShell v26.11.2 · 构建 2026110902

v26.11.2 正式版，以 v26.11.2-rc.11 功能为基线，汇总 rc.1–rc.11 全部改动。构建号高于该版本线全部 rc，rc.1–rc.11 用户可直接内置更新升级到本版本。

新增：候选栏与本机提示符支持 `tcping 主机 端口 [-t]` 与 `telnet 主机 [端口]`：内置 TCP 握手探测与拨号会话，失败映射中文短文案，telnet 远端关闭后本标签重拨；统一开关位于设置 → 其他功能，默认开启。
新增：设置 → 外观配置 → 全局主题：经典与毛玻璃两套整套界面材质，重绘面板、菜单、对话框与强调色而非仅换背景，与明暗、字体、ANSI、布局正交，切换不重建终端、不中断连接；毛玻璃为液态玻璃折射材质（双层流动光场、棱镜边缘、Shell 区半透明），暂仅支持深色主题，浅色自动按经典渲染；不支持透明模糊、减少透明度或高对比时自动回退实色。
新增：同服务器会话 Xshell 语义：双击已连接标签复用同一条 SSH 连接再开独立终端渠道，不再拨号、不认证、不核指纹；最后一个标签关闭才断开；标签菜单「复制独立会话」生成「原会话名-clone」并重新拨号，编号从最小空缺回填。
新增：手动「检查更新」先选版本通道：release 只查正式版资产，rc 通道读取完整 Releases 列表；启动自动检查仍按当前构建类型自动选择。
新增：正在连接时按 Ctrl+C 可取消连接尝试，凭据与指纹核实对话框同样支持取消。
新增：服务器管理「已删除」页底部「一键清理」：确认框列明数量，一次永久删除全部已删除连接及其凭据与连接历史，重复清理幂等。
新增：设置 → 外观配置 →「配色方案」管理页：可一次或分批导入多套 iTerm Color Scheme（.itermcolors），名称沿用导入文件名，同名导入即覆盖，最多 64 套，可应用、重命名或两步确认删除；应用后终端只采用其 16 色 ANSI，背景保持透明、文字颜色仍随字体，真彩色与 256 色语义不受影响。
调整：「链接栏」整体更名为「收藏夹」，入口文案、空态提示与使用手册同步。
调整：移除「背景管理器」整个功能：设置 → 外观配置仅保留字体管理；旧配置中 backgroundId、backgroundOpacity 等残留键加载时自动忽略，其余设置不受影响。
修复：复制渠道会话后新标签立即断开变红（终端被接入两次遭 409 拒绝），并补上初始工作目录。
修复：SSH 握手失败诊断系列——-vvv 事件按完整连接 ID 记录并补 stage=dial 事件；Windows WSA 原始码（10054/10053/10061）正确分类为连接被复位/被拒；弹窗写明拨出的「主机:端口」并列出端口填错、MaxStartups、hosts.deny/fail2ban、代理链路等常见原因。
修复：服务器管理「已删除」页在回收站为空时整排按钮连同整行被隐藏；现备份、恢复与 RDP 会话在所有页签始终在栏内。
修复：telnet 拨号成功后连接挂起、无法关闭；监控栏顶部空白处无法拖动窗口。
