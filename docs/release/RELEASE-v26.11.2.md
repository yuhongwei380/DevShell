# DevShell v26.11.2（开发线，当前 rc.1）· 构建 2026110402

本文件为 v26.11.2 版本线的基线发版说明；正式版发布时将汇总全部 rc 改动重写。
当前内容对应 v26.11.2-rc.1：

新增：候选栏与本机提示符支持 `tcping 主机 端口 [-t]`：内置实现的 TCP 握手探测，默认 4 次、每次 3 秒超时；`-t` 每 500ms 连续拨号，Ctrl+C 停止并汇总；失败映射为中文短文案（端口拒绝连接 / 连接超时 / 域名解析失败）。
新增：`telnet 主机 [端口]`（默认 23）在本标签拨出 TCP 会话：终端中继与 SSH / 串口 / 本地终端复用同一协议，telnet IAC 协商就地回 WONT/DON'T、子协商丢弃，屏幕无乱码；远端关闭后标签落回本机提示符并保留内容，`reconnect` 或再输一次 `telnet` 在本标签重拨同一地址。
新增：设置 → 其他功能 → 「候选栏 TCP 工具」统一开关（默认开启）；关闭后 Tab 候选不再出现这两条命令，后端探测与会话端点一并拒绝。
新增：设置 → 外观配置 → 主题管理：把当前整套外观（明暗模式、界面与终端字体颜色、ANSI 预设、背景与强度、终端字号、曲线样式、提示符颜色）保存为独立主题，支持从当前外观新建、应用、重命名、复制与两步确认删除；应用时整套生效，主题引用的字体或背景若已被删除会报错并保持当前外观不变。
