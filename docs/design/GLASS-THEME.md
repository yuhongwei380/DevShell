# 毛玻璃主题与主题配置

2026-11-04。产品已接入；交互设计稿见 `glass-theme-preview.html`。

## 设计约定

以用户提供的 macOS 终端参考图为方向：低饱和暖色透光、细亮边、微弱内高光和克制阴影。暗模式保留现有烟灰外观，新增同一材质语言的暖雾白明模式。不增加背景图片。

## 统一主题配置

入口：设置 → 外观配置 → **主题配置**，位于原背景管理器上方。

- 系统内置「经典」与「毛玻璃」在同一列表展示，点击立即应用并保存。
- 两套主题均支持浅色、深色、跟随系统；顶栏太阳 / 月亮按钮可手动切换，手动选择会退出跟随系统。
- 风格与明暗模式独立保存，切换风格沿用当前明暗偏好；操作系统通知只更新显示，不覆盖用户选择。
- 切换不重建终端，不中断 PTY，保留字体、字号、自定义文字颜色、ANSI 色、布局和连接状态。
- 字体管理独立保留；两套主题均可分别设置浅色、深色的界面文字颜色。

保留原背景管理器、图片导入与背景强度，以及其他原有设置入口。经典主题继续使用原来的背景选择；毛玻璃不加载或显示背景图，切回经典后恢复原背景。明暗跟随系统的原开关保留，与主题配置中的模式选择同步。

## 材质与配色

| 角色 | 浅色 · 雾白 | 深色 · 烟灰 |
| --- | --- | --- |
| 工作台 | `#e8e6df` | `#393633` |
| 内容表面 | `#faf9f5` / 76% | `#2f2e2c` / 79% |
| 顶栏 | `#fffefa` / 82% | `#3d3c39` / 84% |
| 连续侧栏 | `#f1f0ea` / 72% | `#302f2c` / 76% |
| 浮层 | `#fcfbf7` / 96% | `#302f2c` / 96% |
| 主要 / 次要文字 | `#35362f` / `#55574c` | `#e6e2d6` / `#c9c6bb` |
| 辅助文字 | `#66685e` | `#b0ada3` |
| 强调色 | `#526944` | `#c1ceb0` |
| 不透明表面回退 | `#f2f1eb` | `#302f2c` |

两种模式的终端均采用 `#1e1e1d` / 68% 的深色阅读底，实底回退为 `#242423`。默认终端文字暖米色 `#d8d2b5`，自定义文字颜色优先。ANSI 背景与真彩色保持原值。

不使用壁纸或照片。低透明度 CSS 色面和扩散阴影，让橄榄灰、暖棕色轻微透入玻璃；浅色模式减弱透光密度。色面无交互，不遮挡文字，不依赖外部资源。

## 组件规则

- **布局基线**：复用 `v26.11.1-rc.8` 原生界面，保留 304px 监控栏、监控指标顺序、会话栏与 SFTP 的位置、间距、尺寸和原有经典主题。毛玻璃只覆盖配色、材质、阴影与模糊，不设置新的布局或边框宽度。
- **侧栏**：整列连续材质，32px 背景模糊；监控分区透明，不重复模糊。
- **顶栏**：玻璃放在伪元素，避免模糊创建包含块后挤移固定窗口控件。选中会话轻微提亮。
- **终端**：原版圆角、细亮边和单层阴影。仅模糊背景，不模糊文字。
- **文件面板**：同一材质与分隔线；搜索框为内嵌色面，选中行使用低饱和强调色。
- **菜单与弹窗**：更厚的色罩与28px背景模糊，清晰边界和键盘焦点。
- **平台控件**：保留 Windows 与 macOS 各自窗口控件。

## 状态与兼容

`uiStyle: "classic" | "frosted"` 独立持久化，默认经典；现有 `theme: "light" | "dark" | "system"` 适用于两套风格。

启动时通过 `boot.js` 在样式加载前恢复主题。原生窗口保持不透明，材质在应用内部绘制；`terminalTransparency` 仅作为旧配置兼容字段。

保存失败恢复原主题。减少透明度或不支持模糊时使用同色实底；高对比度使用系统画布和边界；减少动态效果时跳过切换动画。
