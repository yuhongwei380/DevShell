# DevShell

**把 SSH 终端、远程文件、服务器监控和常用命令放在一个窗口里。**

DevShell 是一款中文界面的开源 SSH 桌面工具，适合日常管理 VPS、维护 Linux 服务器、编辑远程配置和排查网络问题。支持 Windows、Linux、macOS 桌面（发行包仅提供 Windows 与 macOS），可同时连接多台服务器，并按自己的习惯调整字体、背景、布局和监控曲线。

本说明对应正式版 **v26.10.1 · 构建 2026102401**。本版把 v26.10.0 以来的全部改动统一发布：监控面板固定在左侧并可在外观配置中显示／隐藏，窄窗口终端头部按钮紧凑成组，首次启动 SFTP 面板默认收起，设置新增“外观配置”入口。左侧监控宽度固定为 304 px，右侧 SFTP 固定为 420 px（小窗口下相应收窄），磁盘监控只显示总容量大于 10 GB 的挂载点。[正式版下载](https://github.com/yuhongwei380/DevShell/releases/tag/v26.10.1-build26102401)；构建号已切换为 `YYYYMMDD` + 两位序号，新的构建号数值低于历史十一位构建号，**此前安装的任意版本（含测试版）需手动安装本构建一次**，之后可继续使用内置更新。完整变化见 [更新日志](CHANGELOG.md)。

> **项目来源**：本项目源自上游 [BitsFlowCloud/DengShell](https://github.com/BitsFlowCloud/DengShell) 的 **DengShell v0.03 分支**，在此基础上独立维护。上游改动不再自动同步，已移植的上游改进（构建 107–114）见更新日志。

> **版本号规则**：`vX.Y.Z` —— X 为年份后两位，Y 为月份（不补零），Z 为当月第几个版本（从 0 起）。例如 2026 年 10 月首个发布为 `v26.10.0`。内部构建号 `ApplicationBuild` 为 `YYYYMMDD` + 两位当日序号（从 `01` 起、上限 `99`），每次发布递增，用于更新防回退；2026-10-24 起由三位序号切换，历史十一位构建号继续有效，已安装旧构建需手动安装新构建一次。

## 功能概览

| 功能 | 可以做什么 |
| --- | --- |
| 服务器管理 | 多级分组、分组拖拽排序、按组浏览与移动连接、名称与地址搜索、表情和国旗图标、批量连接、历史连接、已删除连接恢复 |
| SSH 认证 | 密码、私钥、加密私钥、SSH Agent，首次连接核对主机指纹 |
| 密钥管理器 | 导入与生成密钥、复制公钥、查看指纹、统一保存私钥口令 |
| 代理管理器 | 保存 SOCKS5 / HTTP CONNECT 代理，为各条连接选择代理 |
| 多会话终端 | 新选项卡初始页、单行标签滚动、全部标签下拉列表、断开与重连、会话拆分及窗口合并 |

| 网络诊断 | ICMP 延迟与丢包曲线、本机及远端 MTR、未连接时 `ping 主机` 直接输出到终端（`-t` 持续探测，Ctrl+C 结束）、可用的路由 ASN 信息 |
| 个性化 | 外观配置入口统一管理界面与终端字体、文字和提示符颜色、背景及默认布局；支持明暗主题、跟随系统与缩放 |

## 下载与安装

在本仓库的 **[Releases](https://github.com/yuhongwei380/DevShell/releases)** 页面选择适合自己系统的文件。安装好的程序无需另外安装 Go 或 Node.js。

自 2026-10-20 起发版只提供 **Windows 安装版与 macOS 包**：不再发布 Windows 绿色 ZIP 和 Linux DEB / RPM / pacman / tar.gz。已安装的 Linux 版可继续使用，内置更新检查会明确提示 Linux 已停止发布；历史安装包仍可在 Releases 旧版本中下载。

| 平台与用途 | 下载文件 | 使用方式 |
| --- | --- | --- |
| Windows 10 / 11 x64 安装版 | `DevShell-Setup-x64.exe` | 运行安装器，从开始菜单或桌面启动，可通过控制面板卸载；此前 DengShell 安装版升级时自动沿用原安装目录与数据 |
| macOS 15+（兼容 15 / 26 / 27），Apple 芯片与 Intel | `DevShell-macos-universal.dmg` / `.zip` | 通用应用，临时签名、未公证预览版 |

Windows 版本需要 Microsoft Edge WebView2，缺少时程序会提供安装指引。安装版默认安装到当前用户目录，卸载保留个人配置。

安装器提供运行实例检测：确认后请求同一安装目录下的 DevShell 正常退出，处理未保存编辑与传输，释放占用后自动继续；写入失败回滚旧程序。安装提示框使用 DevShell 图标与精简文案，安装及卸载日志默认折叠。旧版可能需要在应用中确认退出，详见 [安装升级流程](docs/INSTALLER-UPGRADE.md)。

**关于 `up.*` 文件**：Releases 页里的 `up.exe` 及同名 `.json` 描述文件是 **Windows 内置在线更新的载荷**，由已安装客户端的启动更新检查自动下载消费，无需（也不要）手动下载运行。流程：启动时获取描述文件 → 校验构建号大于本机（防回退）→ 弹窗确认后下载并校验 SHA-256 → 替换程序（保留旧程序副本）→ 自动重启，数据目录不变。这些文件名是更新协议的固定契约（见 [更新契约](docs/release/UPDATER-CONTRACT.md)），旧客户端按名字寻找新载荷，不可改名。Linux 载荷 `up.deb` / `up.pkg.tar.zst` 已随 Linux 发版停止，不再发布。

**测试情况：**

- **Windows：** 发布验证覆盖原生 WebView2 启动、安装／卸载保留配置、压缩程序及从最小化状态升级后显示窗口。自动验证使用 GitHub Windows 运行器，结果见 [Windows 验证记录](https://github.com/yuhongwei380/DevShell/actions/workflows/windows-release-validation.yml)；不等同于全部 Windows 10／11 实体设备、显卡和托盘组合已验证。
- **Linux（历史版本）：** 此前 Linux 发行包已在 Ubuntu 22.04、Ubuntu 24.04、Debian 12、Fedora 43、openSUSE Tumbleweed 和 Arch Linux 容器中通过安装、原生界面启动及卸载保留配置测试，具体范围见 [功能审查与验证](docs/release/FUNCTIONAL-AUDIT-v0.03.md)。Linux 发版已停止，源码仍可自行构建。

## 服务器与多级目录

服务器管理左侧显示分组目录，点击分组后，右侧展示该组的连接。各级目录以缩进、连线和级别标识区分，选中后整行突出显示。单击连接可选择、双击打开，Ctrl / ⌘ 可多选后批量打开；右键或“⋯”可编辑、删除、移动到其他分组、定位所属分组和复制地址。

搜索覆盖全部分组；点击路径返回上级，“包含子分组”控制当前列表范围。两栏独立滚动，目录栏可拖动调整宽度，深层目录可横向滚动。栏宽、所选目录及子分组选项会保存。

## 第一次连接服务器

1. 打开 DevShell，点击标签栏左侧的服务器图标，进入 **服务器管理**；也可从初始页点击 **添加或选择服务器**。
2. 选择 **新建连接**，填写名称、服务器地址、SSH 端口和用户名。
3. 选择密码、私钥或 SSH Agent 认证，按需要设置所属分组和连接代理。
4. 点击 **保存并连接**。
5. 首次连接时，通过服务器控制台等可信渠道核对主机指纹，确认一致后选择 **已核实，信任并连接**。
6. 连接就绪后，在终端执行命令，或使用文件面板管理远程文件。

左上角 Logo 右侧的齿轮按钮为 **设置**，齿轮右侧的 **GitHub** 图标可打开本项目代码仓库。顶部不再常驻显示版本文字，点击 Logo 可查看当前软件版本和构建版本；**设置 → 更新日志** 可离线查看当前版本随程序附带的更新说明。需要再次查看帮助时，点击 **设置**，选择“使用手册与功能引导”。内置手册支持搜索、章节跳转和重新查看首次引导。

更新提示与更新日志自动强调条目分类：**新增** 为绿色、**修复** 为橙色、**调整** 为蓝色，并使用固定宽度、加粗及底色标签，让标签和正文起点分别对齐，深浅主题均适配。分类行的列表符号与额外空格不再影响对齐，全角、半角冒号均可识别。颜色标签从构建 144 起支持，旧版程序显示更新提示时仍沿用自身的显示方式，安装并重启后生效。

## 服务器与连接管理

![服务器管理：分组目录与连接列表](docs/images/server-manager.webp)

### 多级分组与搜索

- 按地区、服务商、项目或用途创建分组，也可以继续创建子分组。
- 为分组选择表情或国旗图标，支持按名称和关键词搜索图标。
- 每一级分组均可自定义背景色，自动匹配易读文字；选中目录以边框和勾选标记突出。
- 按连接名称、地址、用户名或分组路径查找服务器。
- 分组支持展开与收起，并保留状态。
- 拖动分组名称可调整同级分组顺序，放置线标明插入位置；也可用 `Alt + ↑ / ↓` 调整，顺序会保存。
- 尚未手动排序的分组及连接按名称排序，支持中文拼音和自然数字顺序，例如编号 `2` 排在 `10` 前面。
- 按住 `Ctrl` 单击服务器进行多选，点击 **打开所选** 或按 `Enter` 发起批量连接。

批量连接时，各台服务器独立连接、独立显示进度。连接失败的标签会保留原因，可单独重试；连接完成后不会抢走正在使用的标签焦点。

### 移动连接到其他分组

1. 在连接上点击右键或 **⋯**，选择 **移动到…**。
2. 从分组列表选择目标组；子分组会显示上级路径，便于区分同名分组。
3. 点击 **移动**。保存后自动切到目标组并选中该连接，原组与目标组的连接数量同步更新。

移动会保留连接名称、地址、备注和已保存的认证及代理信息；取消操作保留原分组。点击左侧 **全部连接** 可查看所有连接，点击具体分组则浏览该组；**包含子分组** 可切换是否显示下级目录的连接。

### 历史连接与回收区

**历史连接**记录成功连接时间和累计次数，便于找到最近使用的服务器。

删除连接后，配置先进入 **已删除**，可以恢复原连接、分组和已保存的认证信息。永久删除需要在回收区再次操作。这里管理的是本机保存的连接资料，远程服务器本身保持原状。

分组菜单的 **删除分组及全部连接** 适用于所有层级。经过三次确认（最后输入分组名称），会永久删除该目录、子目录、所属连接和回收站连接，清理对应连接记录、终端历史与网卡偏好，并断开相关会话。确认期间目录内容变化会阻止删除。全局命令历史、密钥管理器、代理、远程文件和编辑器未保存草稿保留；备份文件仍按原有备份机制保留。

### 密钥管理器

在 **设置 → 密钥管理器** 中，可以导入私钥、生成 Ed25519 密钥、命名密钥、查看指纹和复制公钥。同一把密钥可以绑定多台服务器。

**在密钥管理器中填入并保存私钥口令后，所有引用这把密钥的 SSH 连接都会自动使用该口令，重启 DevShell 后仍然有效。** 旧版已导入的密钥可以通过编辑补填口令。

生成密钥后，需要把公钥配置到远程账号的 `authorized_keys` 中。直接填写外部私钥路径时，口令由该连接的设置管理，文件路径也需要自行保留。

SSH Agent 认证使用本机已配置的 Agent；Agent 的启动与密钥加载由本机环境负责。服务器额外要求的账户密码或多因素验证，仍按服务器的认证要求处理。

### 连接代理

在 **设置 → 代理管理器** 保存 SOCKS5 或 HTTP CONNECT 代理，可填写名称、地址、端口及可选的认证信息。每条 SSH 连接可以选择直连、已保存的代理或自定义代理。

代理设置在重新连接后生效。直连遵循本机路由，因此本机启用的 TUN 也可能影响连接路径。

## SSH 终端与多窗口

每个 SSH 会话使用独立标签，选中的已连接标签旁显示 **当前连接**。终端支持交互式 Shell、命令行编辑器及常见终端程序。

- **新选项卡**：点击 **＋**，打开独立初始页，再选择 **快速连接** 或 **添加或选择服务器**。**＋** 紧跟最后一个会话标签；没有标签时位于服务器管理图标右侧，宽度不足时仍保持可见。切换到初始页会保留已有连接；从初始页发起的前台连接接替当前空白标签，后台打开的连接保留原标签与焦点。
- **选项卡编号**：按当前仍打开的初始页最大编号加一命名；仅剩选项卡 1 时，新建为选项卡 2，全部关闭后从 1 开始，已有编号不会重复。
- **标签导航**：全部标签保持单行，宽度不足时用右侧 **〈 / 〉** 滚动查看；**＋** 始终保留在可见区域。旁边的下拉箭头列出全部标签并标记当前项，点击即可切换 SSH、RDP、串口、进程或初始页标签。
- **调整顺序**：拖动标签可改变排列，连接建立或重新连接后保留相应位置；新建、关闭空白标签不会断开其他连接。
- **断开**：保留当前标签与滚屏内容，方便查看之前的输出。
- **重新连接**：为该服务器重新建立 SSH 会话。
- **清除滚屏**：清理本地显示内容，已执行的远程命令不受影响。
- **调整字号**：使用 `A−`、`A+` 或字号输入框调整终端文字大小。
- **独立窗口**：通过标签右键菜单或拖出标签栏，将已连接会话移入新窗口。
- **合并窗口**：把标签移入同一次启动、共享后台的另一个 DevShell 窗口，也可通过标签右键菜单选择目标。

会话在窗口间移动时保留原 SSH 连接、远程 PTY、当前目录、运行中的程序及终端内容。当前窗口至少有两个 SSH 标签时，工具栏会显示 **独立窗口** 按钮。

Windows 和 Linux X11 支持拖动标签到其他窗口；Wayland 下使用合并菜单。若有待处理的上传任务，按界面提示完成后再移动会话。

### 链接栏

在当前会话工具栏点击 **固定**，即可把连接加入标题栏的 **链接栏**；临时快速连接会先保存为连接配置。点击固定连接总是新建会话，右键可重命名，并与服务器管理中的名称同步。点击 **×** 后确认，只取消固定，不删除连接配置。

链接栏采用无整体外框与背景的样式，保留各连接按钮及 **︙** 菜单。连接按窗口、侧栏和界面缩放后的实际可用宽度排列，放不下的连接收进 **︙** 菜单，点击后即可查看并连接；窗口放大后自动恢复显示。拖拽连接可调整顺序，**︙** 列表中的连接也可拖动，拖到 **︙** 上会展开列表；拖动时有插入位置提示，按 **Esc** 取消。固定列表及排序保存在本机，重启保留。

## 命令历史与快捷命令

### 汇总所有 VPS 的命令

在 DevShell 的各个 VPS 会话中实际提交的命令，会汇总保存到**本机的历史列表**中。例如先在 VPS A 执行 `uptime`，再在 VPS B 执行 `df -h`，打开历史列表即可查找这两条命令。

远端各台 VPS 的 Shell 历史保持独立。DevShell 收集的是通过自身会话提交的命令，其他 SSH 客户端里的操作不在采集范围内。

- 切换服务器后仍可查看完整列表，未连接时也能查看和复制。
- 支持关键词搜索、复制、填入命令输入条和再次执行。
- 点击命令正文先填入输入条，便于修改；点击 **执行** 会发送到历史弹窗显示的 **执行目标** 会话。
- 最多保留最近 **2000 条**，总量上限 **2 MiB**；连续相同的记录会合并。
- 密码提示、尚未提交的文字以及终端程序内部输入不作为命令记录。

完整采集依赖兼容的 Shell 集成，Bash / Zsh 为主要适配对象；其他 Shell 的采集范围可能受限。集成脚本压缩后随终端启动一次性下发，依赖远端存在 `base64` 与 `gzip`（或 `gunzip`），OpenWrt 等嵌入式设备同样适用；缺任一工具时终端照常打开，只是不加载集成。终端输入条的 `↑` / `↓` 仍浏览当前服务器的历史，历史弹窗用于查看所有服务器的汇总。

### 未连接时的本机历史

没有可用连接时（欢迎页，或远端 Shell 已退出、会话只剩本机提示符），命令输入条回车的内容从未进入远端 Shell，因此不进入上面的历史列表，而是单独保留最近 **50 条**本机历史：`ssh 用户@主机`、`ping` / `traceroute` 等本机探测、`reconnect`、`exit` 都算。

- 没有额外按钮，只在未连接时用 `↑` / `↓` 调出；**连接成功后 `↑` / `↓` 只浏览该服务器的命令历史**，两者互不混淆。
- 连续相同的记录会合并，超出 50 条后淘汰最旧的一条。
- 调出后再手工修改文字，下一次按 `↑` 从最新一条重新开始，不会继续往更深处跳。
- 本机历史在所有窗口之间共享，重启后保留；历史弹窗的 **清空历史列表** 只清空 VPS 命令汇总，不影响本机历史。

### 多行输入与快捷命令

在 Shell 提示符下，直接向 SSH 终端粘贴多行命令会自动执行到最后一行，支持 heredoc，无需补按回车。单行粘贴仍可先编辑；`Ctrl+C` 中断当前命令并滚动到终端底部，`Ctrl+Shift+C` 复制选中文字。

终端底部的命令输入条支持先编辑再发送：`Enter` 执行，`Shift + Enter` 换行。

在文件面板的 **命令** 页签，可以把常用操作保存为彩色胶囊按钮。每条命令支持名称、颜色、分组和多行内容；命令区域右键可新建分组，空分组也会保存。

每条命令独立保存 **末尾添加回车 CR**：默认不勾选，仅填入终端；勾选后发送并执行。旧命令缺少此选项时也采用不自动回车。右键命令可编辑、删除或选择“调用前编辑”，按钮旁不再常驻编辑图标。

拖动命令或命令分组可调整顺序，拖到其他分组可移动命令。排序会保存，空分组也保留。

编辑命令时可插入 1–5 号参数，例如 `docker logs [p#1 容器] --tail [p#2 行数]`。调用后在 **命令编辑区** 填写参数、检查实际命令预览，再发送；参数和长命令草稿在本次运行中保留，便于多次调整。发送目标单独显示，打开命令或切换服务器标签时跟随当前会话；手动选择的目标会保留到下次切换标签或打开命令。终端输入条旁的编辑按钮也可展开编辑区。详见 [命令与编辑器说明](docs/release/COMMANDS-AND-EDITORS.md)。

## SFTP 文件管理与编辑

### 文件浏览与排序

文件面板左侧显示目录树，右侧显示目录内容，两部分可以独立滚动。可以通过路径栏跳转目录、返回上级、刷新，或按名称过滤当前目录。

顶部 **SFTP** 按钮可显示或隐藏文件面板。首次启动或没有保存面板显示偏好时默认收起；已保存的显示偏好会在启动时恢复。隐藏后终端自动占满可用工作区；再次显示时恢复文件面板和分隔布局。“拖入文件或文件夹上传”提示左侧的位置按钮可在终端下方与右侧之间切换；右侧宽度固定为 420 px，上方、下方的面板高度可拖动调整并保存。

- **用户与用户组显示实际名称**，例如 `root`；无法解析时显示未知状态。
- 点击 **文件名**、**大小**、**修改时间**表头切换排序方向，箭头标明升序或降序。
- 大小按实际字节数排序，修改时间按实际时间排序，文件夹保持在文件前面。
- 启用 **跟随终端** 后，在支持目录报告的 Shell 中，文件面板可随终端目录变化。

### 上传、下载与传输任务

将本机文件或目录拖入文件面板即可上传，也可以从上传菜单选择文件或文件夹。传输任务页签显示进度、结果和失败原因，支持取消与重试。

上传最多同时处理 **4 个文件**，其余自动排队；单个文件可并行传输多个 SFTP 分块。进度按服务器已确认写入的数据计算。重试从头开始，当前不支持断点续传。

文件操作全部在右键菜单里：右键文件或目录可以打开、重命名、删除、快速删除、复制路径、修改权限；**单个文件可直接下载**（**下载**，保留原文件名，不打包），需要连同目录结构或一次取回多项时使用 **打包并下载**，打包通过 SFTP 读取内容，在本机生成压缩包。多选后菜单提供删除所选、打包并下载与复制路径，键盘 **Delete** 同样删除所选。状态栏只保留项目计数与 SFTP 标识，不再常驻下载 / 重命名 / 删除按钮。文件区的 **＋** 按钮及空白处右键菜单提供新建文件和文件夹入口。

删除与快速删除都会先显示目标服务器和完整路径；远程文件删除后，无法从连接管理器的回收区恢复。

### 终端里的 rz / sz（lrzsz）

DevShell 不实现 ZModem 协议，服务器上的 `rz` / `sz` 不会像 Xshell / MobaXterm 那样直接传输。检测到 Shell 确认的 `rz` / `sz` 命令且看到 ZMODEM 握手后，DevShell 会先中止这次握手（不再刷出 `**B0100000023be50e…` 这类乱码），再改走 SFTP：

- `rz`：打开本机文件选择，上传到终端当前所在目录（跟随终端时以 Shell 报告的目录为准）。
- `sz 文件名…`：直接通过 SFTP 下载这些文件；`-a` 之类选项与 `--` 按 Shell 语义跳过，支持引号包裹的文件名。
- 无法确认命令来源时（未启用 Shell 集成，或 `rz` / `sz` 在脚本、TUI 内部被调用），只中止握手并给出提示，请在文件面板里上传或下载。

文件选择框在首次识别握手后立即触发，无需等待后续重试；同一次尝试的重试不会重复打开选择框，返回 Shell 提示符或开始下一条命令后停止补发中止字节。同一时刻只打开一个本机选择框，当前窗口内按操作类型记住上次目录。

Windows 的本机文件和目录选择框与终端界面隔离鼠标输入状态；选择框打开期间暂时禁用主窗口，关闭或取消后恢复。

Windows 保存框不再预先创建目标文件，避免系统预检查误报无写入权限；实际下载仍使用临时文件并在完成后替换目标，真实的写入失败会正常显示。

需要真正的 ZModem 语义（例如脚本里的 `rz`）时，请改用 SFTP 传输队列或 scp / sftp。

ZMODEM 有公开协议规范，也有开源实现：[lrzsz](https://www.ohse.de/uwe/software/lrzsz.html) 使用 GNU GPL，[zmodem.js](https://github.com/FGasper/zmodemjs) 使用 Apache-2.0。DevShell 当前使用 SFTP 桥接是功能实现现状，并非因为 ZMODEM 闭源。

### 内置文本编辑器

双击文本文件，或右键选择 **打开**，即可在内置编辑器中修改并保存到服务器。

长文本按窗口宽度自动折行，连续英文、网址和无空格长串也能完整阅读。左侧行号仍按原文件的逻辑行显示，并与折行、窗口大小及字体缩放同步；显示折行不会改变复制、保存、编码或原有换行。

多个文件各有独立标签，显示所属服务器、文件名、未保存标记和 **当前查看**；可以同时打开不同服务器的文件。点击“移到新窗口”拆分为应用内可拖动编辑窗口，每个窗口具有自己的标签栏，也可合并回其他编辑窗口。

每个文件分别保留内容、编码、光标与撤销记录，保存始终指向原服务器和路径。关闭未保存文件会提示；原连接断开后保留草稿供复制，不会改存到当前其他连接。收起窗口后点击文件工具栏“文本编辑器”恢复。

| 项目 | 支持情况 |
| --- | --- |
| 编码 | UTF-8、带 BOM 的 UTF-8 / UTF-16、GB18030、GBK、Big5 |
| 文件大小 | 单文件最大 8 MiB |
| 文本格式 | 保留原有编码、BOM、空格与换行形式 |
| 编辑操作 | 保存、撤销、复制全文，`Ctrl + S` 保存到服务器 |
| 修改冲突 | 保存前检查远程文件是否变化，发现冲突时停止覆盖 |
| 保存方式 | 使用临时文件替换，保留基本权限与所有者；不支持相应操作时显示原因 |

无法明确识别编码时，需要手动选择；所选编码无法表示的字符会阻止保存。对依赖 ACL、扩展属性或硬链接身份的特殊文件，应使用能保留这些属性的系统编辑工具。

也可以选择系统关联程序或自定义编辑器打开下载到本机的副本。外部编辑后的内容需要手动上传。

## 服务器状态与网络诊断

### 安全锁定

在 **设置 → 安全锁定** 中启用，至少配置一种解锁方式：密码至少 4 位（可设置公开显示的密码提醒），或使用验证器 App 扫码绑定 2FA，输入当前 6 位验证码后保存。两种方式均启用时，可任选一种解锁。二维码在本机生成，验证码离线验证，每 30 秒变化；已使用的验证码不能重复使用。修改或关闭锁定需要先验证现有密码或验证码。

可选择仅手动锁定，或无操作 1～604800 秒后自动锁定。明暗按钮右侧的锁形按钮立即锁定全部窗口；锁定后界面深度模糊，点击“解锁”输入密码或验证码。鼠标、键盘等实际操作会重置计时，后台监控和终端输出不会。启用后重新启动程序也需要解锁，连续输错会短暂限制重试。

锁定保护 DevShell 主窗口和独立窗口的界面操作，已有 SSH 连接与已开始的任务继续运行；外部编辑器窗口不属于此锁定范围。请保管好密码或验证器。密码仅保存哈希；2FA 密钥和锁定配置加密保存在数据目录的 `dengshell.security-lock.enc`，不随连接配置导入导出。完整迁移/备份时需保留整个数据目录及原有配置密钥。

### 系统、进程与磁盘

连接后可查看远端发行版名称与图标、运行时间、CPU、内存、SWAP、系统负载、磁盘容量及读写速度。磁盘容量位于资源进度条最下方，仅显示总容量大于 10 GB 的挂载点，分别展示使用率及已用 / 总容量，不再显示合计行；悬停可查看完整路径与可用空间。容量单位与界面一致，按 1024 换算；文件系统不等同于物理磁盘，同一磁盘的独立分区也会分别列出，重复挂载不重复统计。读取、写入速度保留独立色块，位于网络流量卡片上方。

**活跃进程** 常驻显示前五行，可切换 CPU 或内存排序。CPU 使用同一进程的内核累计时间差计算，单核满载为 100%，多线程可超过 100%。

点击进程区域可打开当前 SSH 的独立进程标签。完整列表支持 PID／名称／状态搜索、列排序、分页（默认 100 行，最多 200 行）和暂停刷新。各服务器的搜索、分页和暂停状态独立。切走标签停止该页面请求；关闭进程标签保留 SSH。完整列表展示带 `≈` 的轻量 RSS 估算值，只查询当前页的进程用户，不对全机进程扫描内存页。进程采样与侧栏共用缓存，超过 5,000 个进程时降低频率，慢采集或失败会继续退避。

内存先用内核计数筛选前五候选，再通过独立通道读取 `smaps_rollup` 的精确 RSS；不支持时使用 `smaps`。CPU 与内存两个候选列表合计最多精读十个进程，避免对所有进程遍历内存页。候选排名不是全机同一时刻的精确内存排名。数字显示两位小数，悬停可查看完整字节数、读取来源和采样时间；没有精确结果时显示 `—`，失败可保留带采样时间的旧值。精读独立限时并自动退避，不阻塞终端、网速和系统监控。

监控主要面向 Linux 服务器，数据取决于远端系统接口和账号权限。尚未取得有效数据时显示 `—`。

### 上行与下行流量

每条已连接的 SSH 会话独立采集网卡流量，约每 **1 秒**读取一次，显示最近 **60 秒**的曲线。切换标签或最小化后，已连接会话的网络历史仍在后台记录。

CPU、内存、负载与磁盘速率约每 **5 秒**按可见状态更新，网卡信息和磁盘容量约每 **30 秒**刷新。

上行表示服务器发送数据，下行表示服务器接收数据。读数使用 `B/s`、`KiB/s`、`MiB/s`、`GiB/s`，按 1024 进位，并随近期数据自动调整纵轴范围。延迟返回但计数连续的样本按实际间隔求平均，悬停读数可查看该间隔；采样失败、网卡计数重置或长时间暂停会保留缺口。

支持选择网卡，查看其地址信息。公网 IPv4 / IPv6 仅在能够确认时显示；NAT 入口与服务器出口可能不同。

### 独立设置曲线样式

![曲线样式设置界面](docs/images/chart-styles.webp)

打开 **设置 → 曲线样式**：

| 曲线 | 可独立调整 |
| --- | --- |
| 上行网速 | 实线 / 虚线、线条粗细、颜色 |
| 下行网速 | 实线 / 虚线、线条粗细、颜色 |
| 延迟 | 线条粗细、颜色 |

线条粗细范围为 **0.5–6 px**，颜色可以自定义或跟随明暗主题。设置时可预览，每条曲线都可单独恢复默认；点击 **保存设置** 后，重启仍会保留。

### ICMP 延迟与 MTR

ICMP 面板展示本机到目标的延迟、最近 **1 分钟**丢包率和连续曲线。超时、不可达或缺测会单独标识；悬停或使用方向键可查看对应采样的读数和状态。

MTR 支持从本机探测服务器，也可从远程服务器探测指定目标，查看逐跳响应和可用的 ASN 信息。缺少工具时，会先展示安装方案，经确认后安装。

未连接任何服务器时，底部命令输入条即为**本机提示符**，可直接输入 `ping 主机`、`traceroute 主机`、`nslookup 主机`、`dig 主机 [记录类型]`、`curl [-I] 网址`，结果直接输出到终端（`ping -t` 持续探测）。`traceroute` 逐跳实时显示路由结果，任何运行中的本机命令按 **Ctrl+C** 即可中途停止。输入时按 **Tab** 会补全这些功能命令（含 `ssh`、断开会话后的 `reconnect` / `help` / `exit`），并在输入条上方弹出候选框显示参数格式；连续按 Tab 循环切换候选，Shift + Tab 反向，输入、回车或 Esc 收起。此处输入过的命令单独保留最近 **50 条**，按 `↑` / `↓` 调出，见[未连接时的本机历史](#未连接时的本机历史)。

![未连接时本机提示符 ping 直接输出到终端](docs/images/local-prompt.webp)

ICMP 走本机路由或 TUN，不经过应用设置的 SOCKS5 / HTTP 代理；其读数不能直接代表 SSH 代理链路或按键响应。中间路由器可能限制探测回应，需要结合后续节点与目标结果判断。

## 字体主题与布局

![Shell 字体与颜色设置界面](docs/images/appearance.webp)

### 字体与文字颜色

设置 → **外观配置** 集中管理 **界面字体与文字颜色**、**Shell 字体与颜色**、**提示符颜色**、**背景管理器**和**恢复默认布局**；界面与终端字体分别独立保存。

- 界面仅内置 **阿里巴巴普惠体 3.0（Alibaba PuHuiTi）**。浅色、深色界面文字颜色分别设置、保存和恢复默认。
- Shell 内置 **JetBrains Mono、Fira Code、Source Code Pro、IBM Plex Mono、Maple Mono CN**；Maple 同时作为中文回退，无需再携带第六套字体。
- **在线字体库**提供 20 款界面字体和 30 款 Shell 字体（包括已内置的款式）。先看真实字形图片，确认后下载完整字体；下载完成可立即使用，重启后仍可离线使用。列表与许可证可离线查看，在线样张需要网络。
- 下载显示进度，支持取消、重试和删除本机副本；校验固定官网来源、文件大小、SHA-256 与字体格式。下载失败保留当前字体。
- 旧版已移除的内置字体自动回退到默认款式，原有自定义字体、配色、加粗和其他设置保留。需要旧字体时可从在线库重新选择。

- 支持导入 TTF、OTF、WOFF 和 WOFF2 字体（每个最大 64 MiB）。手动导入的界面字体需完整退出并重启后生效，Shell 字体可立即切换。
- 字号范围 **8–40 px**，按 **0.5 px** 调整，也可直接输入数值。
- 每款字体分别保存加粗与文字颜色，切换字体时应用对应样式。
- 配色支持预设色、RGB、HEX 和颜色选择器，窗口可拖动并实时预览。
- 外观配置中的提示符颜色可分别调整用户名与主机名；在兼容的 Bash / Zsh / Fish 中于下一次提示符显示时生效。

字体均保留各自的 OFL 1.1 许可证。部分繁体优先或展示风格字体的简体覆盖较少，库中说明回退方式。自定义字体的等宽效果和符号覆盖取决于字体本身；远程程序主动设置的 ANSI 颜色会保留其含义。

### 主题、背景与窗口

- 支持浅色、深色主题，以及 **明暗跟随系统**。
- 主题切换有渐变效果，并尊重系统的减少动态效果偏好。
- 设置 → 外观配置 → 背景管理器提供内置背景，也可导入 PNG、JPG、WebP 图片并调整显示强度。
- 信息栏可以放在终端左侧或右侧。文件区可通过上传提示左侧的位置按钮切换至终端下方或右侧，设置中也保留终端上方布局。
- 监控栏宽度固定为 304 px，右侧文件面板宽度固定为 420 px；小窗口仅限制文件面板宽度以保留终端空间。上下布局仍可拖动分隔条调整文件面板高度并保存；设置 → 外观配置可恢复默认布局。
- 界面缩放与终端字号分别调整，窗口尺寸和偏好会保存。
- 最小化可选择普通最小化或托盘，并记住选择；Linux 托盘需要桌面提供相应服务。

## 常用应用

文件区的 **常用应用**提供以下入口，操作内容及结果显示在当前 SSH 终端中。

| 工具 | 作用 |
| --- | --- |
| BBR 优化 | 使用现有内核 BBR，提供保守、平衡、激进三种参数方案，应用前检查并备份 |

## 配置备份与升级

### 数据保存在哪里

在 **设置 → 连接配置文档** 查看当前程序实际使用的数据目录。

| 使用方式 | 默认数据位置 |
| --- | --- |
| Windows 安装版 | 当前用户安装目录内的 `data/` |
| Windows / Linux 便携版 | 程序旁的 `data/` |
| Linux DEB、RPM、pacman 或通用安装版 | `${XDG_CONFIG_HOME:-$HOME/.config}/dengshell` |

指定 `--config` 时使用指定的数据目录，以应用显示的实际路径为准。

连接资料、保存的凭据和偏好存入本地加密配置；导入的私钥、字体和背景跟随数据目录。配置使用 AES-256-GCM，自动解锁密钥保存在同一目录，因此拥有该目录读取权限的程序仍可能取得数据。在连接提示里临时输入的密码或口令，连接成功后会自动写入该连接的保存凭据（提示框会事先说明；连接失败后重新输入的凭据会替换旧值），下次连接同一连接不用再输。保存新连接时取消勾选「记住凭据」，该连接在本次运行中不再自动回写。

### 如何备份与迁移

1. 退出 DevShell。
2. 备份整个实际数据目录，包括 `dengshell.config.enc`、`dengshell.config.key`、`assets/` 和 `keys/`。
3. 在目标电脑退出程序后，将备份放入它的实际数据目录，再启动。
4. 手动填写的外部私钥路径需要另行复制并检查。

加密配置与解锁密钥需要一起备份。导入管理器的字体、背景和私钥已复制到数据目录，原导入文件移动后仍可使用。

### 升级

启动时可以检查新版本，确认后下载并校验大小、SHA-256 与更高构建号；描述一旦携带任何签名字段，则必须通过 Ed25519 与有效期校验（本分支发布未签名描述，信任锚是 GitHub Releases 的 HTTPS 来源加 SHA-256，见 [更新器约定](docs/release/UPDATER-CONTRACT.md)）。在线更新载荷：Windows `up.exe`；macOS 通用应用包 `DevShell-macos-universal.zip`，配 `up-macos-arm64.json` / `up-macos-amd64.json` 两份描述。自 2026-10-20 起 Linux 停止发版，已安装的 Linux 客户端检查更新时会看到「Linux 版已停止发布更新」的明确提示，当前版本可继续使用，历史安装包保留在 Releases 旧版本。当前属于退出并重启的更新方式（Windows 替换程序，macOS 原子替换 `.app` 并自动启动新版本），不保留正在运行的 SSH 会话；GitHub 发布本身不自动部署官网的更新文件。

检查更新与下载共用代理策略：优先读取对应协议的 `HTTPS_PROXY` / `HTTP_PROXY`，其次 `ALL_PROXY`（兼容小写名称），并遵守 `NO_PROXY`。未设置环境变量时，Windows 跟随当前用户的系统代理（包括 FlClash 系统代理和可解析的 PAC）；Linux 读取 GNOME 或 KDE 的手动代理。支持 HTTP CONNECT、HTTPS 代理和 SOCKS5；代理地址变化在下一次请求生效，正在下载的连接需取消后重试。没有代理时直连；已配置的代理连接失败不会偷偷改为直连。Linux 自动代理脚本尚不支持，可改用系统手动代理或上述环境变量。SSH 连接仍使用各自的连接代理设置。

手动升级时先退出程序，替换程序文件或安装新版，并保留原数据目录。升级会中断当前 SSH 会话。Windows 安装版卸载保留个人数据；从便携版改用 Linux 安装版时，可按实际目录迁移备份。

## 常见问题

**保存了私钥口令，连接时还会要求输入吗？**

从密钥管理器选择的密钥，只要口令已在管理器中保存，引用它的连接就会自动使用。若仍出现提示，先核对是否选中了同一把库内密钥，再确认提示要求的是私钥口令，还是服务器额外要求的账户密码或其他认证。

**历史列表能看到所有 VPS 的命令吗？**

能汇总在 DevShell 各会话中实际提交、且被兼容 Shell 集成采集到的命令。记录保存在本机，受最近 2000 条和 2 MiB 的上限限制；其他客户端输入的命令不会自动导入。

**文件管理器能按大小和修改时间排序吗？**

可以。点击对应表头即可切换升序、降序；排序使用实际大小和时间值。

**曲线颜色和粗细重启后还在吗？**

在 **设置 → 曲线样式** 中点击 **保存设置** 后会保留。上行与下行还可以分别选择实线或虚线。

**为什么网速或延迟有时显示缺口？**

缺口表示当时未取得有效采样，例如探测超时、连接异常或接口不可用。图表按实际结果显示，不把缺测当作零流量或零延迟。

**外部编辑器保存后，服务器文件会自动更新吗？**

外部编辑器修改的是本地副本，需要手动上传。使用内置编辑器的 **保存到服务器** 或 `Ctrl + S`，才会直接保存到远端。

**换电脑时只复制 EXE 就够了吗？**

程序可以独立启动；要带走原有连接、密钥、历史和个性化设置，还需要完整复制数据目录。
